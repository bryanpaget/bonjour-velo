Fleet Overview

10,000+ bikes across 1,000+ stations, operated as a single national program. Every kiosk, charge node, and telemetry pipeline runs on Kubernetes.

ServiceDescriptionRuns on
bonjourvelo-apiGBFS feeds + station telemetry APIKubernetes · 2 replicas · HPA
station-kioskPer-station checkout worker podsKubernetes · rolling deploy
charge-nodeE-assist battery swap schedulersKubernetes · stateful set
ops-dashboardNational fleet health + utilizationKubernetes · stateless

Deploy the National Fleet

make validate   # client-side check of the Kubernetes manifests
make deploy     # kubectl apply -k k8s → national rollout
